Where the uncertainty comes from

    

      Each bar swings one stage across its own lo/hi with every other stage
      held at its mode. The longest bar is where more research would pay off
      most. Mass-only stages register zero — they cannot move a count however
      uncertain they are.
    

    

  


  

    
Distribution of the answer

    

  


  

    
How the floor becomes the requirement

    

      Every count-affecting stage, in order, compounding on the one before it.
      This walk uses each stage's mode, so it lands slightly below the
      headline figure above, which is the mean of the Monte Carlo draws.
      The two differ because the lo/mode/hi bands are asymmetric — several
      stages have more room to go wrong than to go right, which drags the mean
      above the mode. That gap is a real feature of the data, not a rounding
      artefact.
    

    

    

  


  

    
Evidence behind the count

    

      Counting only stages that can move the count. Mass-only stages are
      excluded because their evidence quality is irrelevant to this answer.
    

    

  







  

    
The mixing simulator

    

      Drag the pool size. This is the whole argument of the project in one
      control: six chickens is only reachable if you cut up six chickens
      yourself. Add any pooling at all and the count runs for the ceiling.

Average broiler live weight by state

    

      Ohio runs 4.6 lb birds. North Carolina runs 8.4 lb birds. Same species,
      same year, different businesses — small-bird programs feed fast food,
      big-bird programs feed deboning.
